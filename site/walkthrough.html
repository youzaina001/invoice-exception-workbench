Walkthrough

This page is the invoice walkthrough for the hosted demonstration. A Reviewer is an invited person who acts as the Operator inside their own Demo Workspace. The Operator investigates an incomplete supplier invoice and resolves its exception case. The Maintainer owns the demonstration and may inspect every Demo Workspace. Hosting limits, the €0 budget, and publication status are on the landing page.

Sample CSVs

The Reviewer uploads these two files in the hosted demonstration. Download them here:

  • missing_amount.csv — the amount is empty, so the check opens a case.
  • corrected_amount.csv — the same invoice with the amount filled in.

Steps

  1. The Maintainer creates the Reviewer's invitation in the Clerk dashboard. Clerk sends the email. The application does not send mail and does not offer an invite screen or public registration.
  2. The Reviewer signs in. The first sign-in creates one Demo Workspace and one Demo Attempt. That Demo Attempt starts with no invoices.
  3. The Reviewer ingests missing_amount.csv, then runs checks on the current submission. The missing amount opens a case.
  4. The Reviewer ingests corrected_amount.csv and runs checks again.
  5. The Reviewer opens the case and uses Resolve case. Resolve closes the case only when the current check allows it.

Signing out and returning

Signing out and returning resumes the same Demo Attempt, including its submissions, cases, check results, and audit evidence. Signing out does not reset the work.

Start fresh

Start fresh opens a new Demo Attempt that contains no invoices. The previous Demo Attempt stays readable in the same Demo Workspace, including its audit evidence. Ingest and resolve against that previous Demo Attempt are refused.

Five Demo Attempts

A Demo Workspace keeps at most five Demo Attempts. The first sign-in creates the first. Each Start fresh adds one. When the Reviewer already has five, Start fresh deletes the oldest attempt in that workspace, including its submissions, cases, check results, and audit evidence, and the workspace again holds five. That deletion does not change any other Reviewer's Demo Workspace.
